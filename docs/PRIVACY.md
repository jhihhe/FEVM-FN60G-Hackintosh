# 隐私与验证范围

当前公开 config 的 MLB、SystemSerialNumber、SystemUUID 为空，ROM 为六字节零。使用前请自行生成并填写，不要把填好四码的文件提交到公开仓库。

公开包仅提供 EFI/BOOT 与 EFI/OC，不带 Microsoft/APPLE 目录、机器日志、NVRAM 转储、个人备份或旧硬件截图。发布前对公开 EFI 扫描了原机器四码的文本及二进制形式和本机路径，未发现匹配；同时清理了界面 PNG 的文字/EXIF 元数据（如有）。这不构成对第三方二进制所有内容的来源审计。

按机主要求，旧 Git 历史、标签和发行版保留，未执行历史重写。旧附件和历史截图不属于本次脱敏范围。

机主确认的是原日用配置完整回归正常。公开包经过脱敏、旧变量和无效监控辅助驱动清理；检查覆盖 plist 解析、启用文件引用、重复驱动标识、禁止组件和隐私占位符。公开包本身尚未重启测试，其他硬件组合需要各自验证。
